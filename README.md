# منصة الرياضيات التفاعلية – الصف العاشر – سلطنة عُمان (الفصل الدراسي الأول)

منصة تعليمية رقمية متكاملة (تطبيق ويب متجاوب قابل للتثبيت PWA) لمادة الرياضيات للصف العاشر، مبنية على **كتاب الطالب** و**كتاب النشاط** – الفصل الدراسي الأول (الطبعة التجريبية 1443هـ / 2021م). المنصة مفتوحة للطلاب دون تسجيل، ولها لوحة إدارة محمية للمعلم.

## البنية التقنية

- **Next.js 15 (App Router) + React 19 + TypeScript + Tailwind CSS**، اتجاه RTL كامل، خط IBM Plex Sans Arabic، دعم الأرقام العربية/الهندية (زر في الأعلى) والوضع الليلي وتكبير الخط.
- **الرياضيات**: محرك خاص دون `eval` في `src/lib/math/`:
  - `expr.ts` محلّل عبارات (أرقام هندية، س/ص، جا/جتا/ظا، ضرب ضمني، رسائل خطأ عربية للقسمة على صفر…) واختبار التكافؤ الجبري.
  - `poly.ts` كسور جبرية بمعاملات نسبية: تحليل إلى عوامل، تبسيط، عمليات مع خطوات، قيم مستبعدة.
  - `stats.ts` بطرق الكتاب: الربيع الأدنى في الموقع ¼(ن+1) مع متوسط القيمتين المجاورتين، الوسط التقديري بمراكز الفئات، الفئة الوسيطية، كثافة التكرار، قراءة الوسيط من المنحنى التراكمي عند ن÷2.
- **العرض الرياضي**: مكوّن `MathText` بترميز خفيف (`\frac{}{}`، `^`، `_`، `\sqrt{}`، `\le`…) يعرض الكسور والأسس بالعربية من اليمين إلى اليسار دون مكتبات خارجية (يعمل دون اتصال).
- **الرسوم**: SVG مكتوب للمنصة (`Plane` مع سحب النقاط باللمس وقص المناطق، مخططات إحصائية، نظريات الدائرة) وCanvas للسبورة.
- **التخزين**: تقدم الطالب وملاحظاته في `localStorage` على جهازه فقط. بيانات الإدارة في Supabase (اختياري) أو ملف `data/store.json`.
- **الذكاء الاصطناعي**: `src/app/api/tutor/route.ts` يستدعي Claude عبر `@anthropic-ai/sdk` في الخادم فقط مع البث، وحدود للطلبات لكل جهاز/ساعة وحد يومي إجمالي، وسياق المنهج والدرس، وتعليمات تمنع اختراع قوانين وتوجّه الطالب بالتلميحات. المفتاح لا يصل إلى المتصفح.
- **الأمان**: `src/middleware.ts` يحمي `/admin` و`/api/admin` بجلسة موقّعة HMAC (Web Crypto)، وتحقق إضافي من الدور والبيانات في كل واجهة (`api/admin/data`)، وحماية من CSRF بفحص الأصل، وإبطاء تخمين كلمة المرور.
- **PWA**: `public/sw.js` يخزّن الصفحات الأساسية وجميع الدروس وملفاتها عند التثبيت، الشبكة أولاً للصفحات ثم التخزين، ولا يخزّن واجهات المعلم الذكي أو الإدارة. شريط حالة يظهر عند انقطاع الاتصال.

### هيكل المحتوى

```
src/content/
  curriculum.ts        الوحدات (معرّف ثابت u1…u8، صفحات الكتاب، الألوان)
  lessons/u1.ts …      الدروس: أهداف، أجزاء (Sections/Blocks)، قوانين، أمثلة، مهارات…
  questions/u1.ts …    بنك الأسئلة: لكل سؤال معرّف ثابت q-<درس>-<رقم> ودرس ومهارة وصعوبة ونوع
  generators.ts        مولّدات أسئلة بقيم عشوائية (الإجابة تُحسب برمجياً)
  gameContent.ts       محتوى «اكتشف الخطأ» و«أكمل الحل» وبطاقات التصنيف
  types.ts             نموذج البيانات
```

المعرّف الداخلي للدرس مثل `1-2` (الوحدة-الدرس)، ويُعرض للطالب كما في الكتاب «2-1». يضيف المعلم محتوى (أسئلة، اختبارات، شروحات، إعلانات) من لوحة الإدارة فيظهر فوراً دون إعادة بناء التطبيق.

## النسخة المبسّطة للطلاب (دون خادم)

```bash
./scripts/build-static.sh      # ينتج المجلد static-site/
```

موقع ثابت يحتوي كل ما يخص الطالب (الدروس، الاختبارات، الألعاب، المختبرات، السبورة، الأدوات، الملاحظات، التقدم) دون المعلم الذكي ولوحة المعلم. يُرفع بالسحب والإفلات على Netlify Drop أو أي استضافة ملفات ثابتة.

## التشغيل محلياً

```bash
npm install
cp .env.example .env.local   # ثم عدّل القيم
npm run dev                   # http://localhost:3000
```

متغيرات البيئة (في الخادم فقط):

| المتغير | الغرض |
|---|---|
| `ANTHROPIC_API_KEY` | مفتاح Claude لتفعيل المعلم الذكي (اختياري؛ دونه تظهر رسالة «غير متاح») |
| `AI_MODEL` | النموذج الافتراضي (`claude-opus-5-5`)، ويمكن تغييره من لوحة الإدارة |
| `ADMIN_PASSWORD` | كلمة مرور المدير (8 أحرف على الأقل) |
| `TEACHER_PASSWORD` | كلمة مرور المعلم (اختيارية؛ لا تصل إلى إعدادات الذكاء الاصطناعي) |
| `SESSION_SECRET` | سر توقيع الجلسات (32 حرفاً على الأقل) |
| `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` | تخزين بيانات الإدارة سحابياً (مطلوب على Vercel) |

### إعداد Supabase

أنشئ جدولاً واحداً (من SQL Editor):

```sql
create table if not exists kv (
  key text primary key,
  value jsonb not null,
  updated_at timestamptz default now()
);
alter table kv enable row level security;  -- لا سياسات عامة: الوصول من الخادم فقط بمفتاح service role
```

## النشر على Vercel

النسخة المنشورة: https://smart-student-math10.vercel.app

1. اربط المستودع بـ Vercel (إطار Next.js يُكتشف تلقائياً).
2. أضف متغيرات البيئة أعلاه في إعدادات المشروع (بما فيها Supabase لأن نظام ملفات Vercel للقراءة فقط).
3. انشر، ثم اربط النطاق الخاص من إعدادات Domains.

## ملاحظات المطابقة والمراجعة

تظهر هذه القائمة أيضاً في لوحة المعلم:

- عنوان الوحدة السادسة في الكتاب «التناسب» ويضم درساً واحداً «التناسب الطردي والتناسب العكسي في الحدود الجبرية»، واعتُمد عنوان الكتاب.
- أرقام الصفحات من فهرسي الكتابين (الطبعة التجريبية 2021م) — يُرجى التحقق منها إن صدرت طبعة أحدث.
- المحتوى أصلي (شروح وأمثلة وأسئلة جديدة متوافقة مع المنهج) ولا يعيد نشر نصوص الكتابين؛ بعض الأمثلة تستخدم البيانات العددية نفسها الواردة في الكتاب للتحقق من صحة الطرق.
- المستقيم الأفضل تمثيلاً في الكتاب يُرسم بالنظر؛ يعرض المختبر مستقيماً محسوباً (المربعات الصغرى) مع وسمه «إثرائي»، كما يعرض معامل الارتباط بوصفه معلومة خارج المنهج.
- الكتاب يذكر أسلوبي التظليل (المنطقة المطلوبة/غير المطلوبة)، والمنصة تدعم الاثنين.

## حدود معروفة (بصراحة)

- **المعلم الذكي** مُنفَّذ ومُختبَر من ناحية الواجهة ورسائل عدم التوفر وحدود الاستخدام، لكن جودة ردوده الفعلية تحتاج إلى تجربة بعد إضافة المفتاح على الخادم.
- لا توجد حسابات للطلاب أو مزامنة سحابية لتقدمهم (حسب المطلوب: دون تسجيل). التقارير الفردية متاحة فقط عبر ملف يصدّره الطالب.
- النص الأساسي للدروس جزء من الكود (مراجَع ومختبَر)، ويضيف المعلم فوقه شروحات وأمثلة وأسئلة واختبارات من لوحة الإدارة؛ تعديل الهيكل الأساسي للدروس يتم في ملفات `src/content`.
- تحرير الأسئلة من لوحة الإدارة يدعم: اختيار من متعدد، صح/خطأ، رقمية، قصيرة. الأنواع الأخرى تُضاف في ملفات المحتوى.
- السحب والإفلات في أسئلة التصنيف يعمل بالفأرة، وعلى شاشات اللمس بأسلوب «اضغط البطاقة ثم الفئة».
- العمل دون اتصال يشمل الصفحات المخزنة بعد أول زيارة وتثبيت عامل الخدمة؛ المعلم الذكي ولوحة الإدارة يتطلبان اتصالاً.

## التوسع لصفوف أخرى

النموذج في `src/content/types.ts` لا يفترض صفاً محدداً: يمكن إضافة مجلد محتوى لصف آخر بالبنية نفسها (وحدات/دروس/أسئلة/مهارات) دون تغيير المكوّنات.
